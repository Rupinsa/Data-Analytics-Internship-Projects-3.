# Data Analytics Internship Projects

A collection of two end-to-end data analytics and business intelligence projects developed as part of the internship program.

## Projects Overview

This repository contains both allotted projects:

### DA-01 — Enterprise BI Suite

An enterprise-focused Business Intelligence solution built using Python, DuckDB, SQL, Streamlit and Plotly.

**Key features:**
- Automated ETL pipeline
- DuckDB analytical data warehouse
- SQL analytical views
- Data quality validation
- Sales, finance, HR and inventory analysis
- Interactive executive dashboard
- Regional access demonstration
- Prepared DAX measures and Power Query documentation

**Technology stack:** Python, SQL, DuckDB, Pandas, Streamlit, Plotly.

**Live deployment:** https://enterprise-bi-suite-cwu3juobvixjv4cuvkazpb.streamlit.app/

**Project documentation:** [DA-01 README](DA-01/Enterprise-BI-Suite/README.md)

**Dashboard screenshots:** [View screenshots](DA-01/Enterprise-BI-Suite/screenshots/)

### DA-04 — FinSight AI

An AI-powered financial analytics project focused on financial reporting, data analysis and credit risk modelling.

**Project components:**
- Financial data processing
- Financial reporting and analysis
- Credit risk modelling
- SQL queries and database schema
- Model evaluation and reporting
- Supporting analytics documentation

**Technology stack:** Python, SQL, Streamlit and machine learning libraries.

**Live deployment:** https://finsight-ai-9.streamlit.app/

**Project documentation:** [DA-04 README](DA-04/FinSight-AI/README.md)

## Purpose

These projects demonstrate practical skills in data analytics, business intelligence, Python development, SQL, data processing, reporting, visualization and machine learning.

Both projects have separate public GitHub repositories and live deployments. This combined repository provides a single location for internship evaluation.

## Important Implementation Notes

DA-01 uses DuckDB and Python ETL as local alternatives to Microsoft SQL Server and Azure Data Factory. Power BI DAX and Power Query artifacts are prepared but have not been executed in Power BI Desktop. Production Power BI Row-Level Security and Power BI Service publishing remain pending.

Please refer to each project's README for detailed setup instructions, architecture, features and implementation limitations.
